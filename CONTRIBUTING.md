# Contributing to RepoLens

Thank you for your interest in contributing to RepoLens! This document outlines the process for contributing to the project.

## Code of Conduct

Please be respectful and considerate of others when contributing to this project. We aim to foster an inclusive and welcoming community.

## Getting Started

1. Fork the repository
2. Clone your fork locally
3. Set up your development environment following the instructions in [DEVELOPER.md](DEVELOPER.md)
4. Create a new branch for your changes

## Making Changes

1. Make your changes in your branch
2. Add or update tests as necessary
3. Ensure your code follows the style guidelines in [DEVELOPER.md](DEVELOPER.md)
4. Run tests to verify your changes don't break existing functionality

## Submitting Changes

1. Push your changes to your fork
2. Submit a pull request to the main repository
   - Include a clear description of the changes
   - Reference any related issues
3. Participate in the code review process
4. Make any requested changes

## Pull Request Guidelines

- Keep pull requests focused on a single topic
- Include tests for new functionality
- Update documentation as needed
- Follow the code style guidelines
- Make sure all tests pass before submitting

## Reporting Issues

When reporting issues, please include:

- A clear and descriptive title
- Steps to reproduce the issue
- Expected and actual behavior
- Any relevant logs or error messages
- Environment information (OS, Python version, etc.)

## Feature Requests

We welcome feature requests! When submitting a feature request, please:

- Clearly describe the problem the feature would solve
- Explain how the feature would benefit users
- Suggest an implementation approach if possible

## Questions or Feedback

If you have questions or feedback, please:

- Check existing documentation
- Search through existing issues
- Open a new issue if needed

Thank you for contributing to RepoLens!
